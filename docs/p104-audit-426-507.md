## Method

- **Scratch folder:** `/dev/shm/p104/a426/`, outside Git. Capture paths below are relative to it.
- **Server:** a Vite server on port 46086, started and stopped by this lane.
- **Contact sheets:** `sheets/ID.png` is a 3×3 grid:
  - Top row: the plate, the default view at phase 0, and a right view (yaw +50°, pitch 20°, phase 0.15).
  - Middle row: a left view (yaw −50°, pitch −15°), a top view (pitch 70°) and a back view (yaw 180°, phase 0.5).
  - Bottom row: a below view (yaw 30°, pitch −55°, phase 0.8), phase 0.33 and phase 0.66.
- **Whole-cycle strips:** `sheets/ID-s.png` shows eight phases in the default view.
- **Zooms:** `z/*.png`.
- **Fluid-motion test:** `fl/`.
  - I rendered each water body alone (every other part hidden) at two nearby phases and counted the pixels that changed (ImageMagick AE, 1% fuzz).
  - A count of 0 means the water is frozen.
- **Probes:** `probe.mjs`, `proj.mjs`, `vis.mjs`, `roles.mjs` and `rad.mjs` give bounding boxes, screen motion, visibility, roles and radii.
- **Screens:** all five screens were run over 426–507 with `--jobs=8`. The outputs are `disc.json`, `cf.json`, `white.json`, `edge.json` and `facet.json`.
  - I diffed them against pass 101 (`/dev/shm/p101/r426/`).
  - Changes since pass 101: 506's bearing fight and 462's bank fight are gone. 491 gains a low-poly flag on the barrel, but its chord is 1.1 px, which is invisible.
  - The only lines in range are 457's operator arrow, which `vis.mjs` shows is never visible.
- **Prior context:** I read the ledger rows for 426–507, the p101 audit and the p101-f6, p102-b and p103-a reviews. The fixes they list for 433, 441, 442, 444, 445/446, 447, 448, 450/451, 452, 454, 462, 464, 465, 469, 471, 478, 482, 491, 492, 494, 498 and 506 all show as landed, with no regressions seen.
