# Minimal interface review — 2026-09-18

Reviewer: Codex, primary agent. Scope: shared interface and responsive framing,
not a new source-fidelity, motion, or collision review of all 507 mechanisms.

Removed catalog slogans, entry-count promotion, repeated reconstruction badges,
the generic “Interactive 3D model” box, redundant detail metadata, decorative
numbers, promotional footer, portability copy, and decorative card/panel borders.
Original descriptions and specific mechanical corrections remain. Model-supplied
reconstruction notes are available in a disclosure, which is absent when empty.
The About page retains source attribution and a brief explanation of the models.

The model viewport is square. The engraving and description occupy squares with
half its side length. Landscape uses a 3:2 composition; portrait uses 2:3. The
composition fits the space left after the heading and controls, using container
units and dynamic viewport height. Controls sit outside the composition. Long
descriptions scroll within their square, including by keyboard. Portrait layout
is selected by orientation, including tablets, rather than phone width alone.

Primary-agent screenshot inspection covered movement 010 at 1440×1000,
390×844, 844×390, and 820×1180, the desktop catalog, and the phone About page.
The complete engraving is visible without nested frames; the model fits the
square at the inspected pose. Temporary images are outside Git at
`/tmp/507-minimal-review/`. These are interface checks, not clearance claims.

Validation: production build; catalog/search/navigation and playback controls;
responsive panel ratios, rotation, viewport fit down to 320×568; keyboard scrolling
of movement 015's long description; movement 129 reconstruction disclosure;
064 camera framing after resize and reset; lazy family loading and cancellation.
The existing build warning about large mechanism chunks remains.

All ledger rows reference this shared presentation change. Their existing visual
review attribution, production MuJoCo classification, intersection scope, and
remaining mechanical flaws are retained verbatim. No unverified source review or
unknown intersection status is promoted. Individual framing across every phase
of every mechanism has not been requalified. Small source squares on landscape
phones necessarily require scrolling for long descriptions.
