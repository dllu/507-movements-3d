# 106 — uniform-stroke reversing-groove barrel cam

The catalog route `#/movement/106` uses MuJoCo contact between a rotating barrel
groove and a passive follower. The upper rectangular rod travels through two
hanging guides; one revolution produces a complete reciprocating stroke in
four seconds. Brown's [106 caption](https://507movements.com/mm_106.html)
specifies uniform rectilinear reciprocation from a grooved rotating cam.

The previous model prescribed triangular output motion, with instantaneous
reversals, while drawing a raised black tube on an uncut cylinder. Its large
added support, ring-shaped upper guides, fixed rod and sliding sleeve also
differed from the engraving. The replacement has a recessed continuous groove,
measured hanging guides and frame, a translating rectangular rod, a shaped
follower head, an ordinary crosspin and a rounded working pin.

## Source comparison

`scripts/measure-barrel-cam-source.mjs` reads complete dark ink runs independently
from `public/engravings/mm_106.png`. Each model unit represents 100 source pixels.
The script freezes its inputs and compares the readings with actual rendered
vertices, groove edges and the combined follower silhouette.

| Barrel diameter | 190.54365 pixels |

| Fitted apparent groove width | 19.47773 pixels |
| Groove edges, 161 ink readings | 3.74299 pixels RMS; 13.59085 maximum |
| Follower head and working pin, 87 ink readings | 2.05684 pixels RMS; 9.17740 maximum |

The drawn groove is irregular. A piecewise linear travel law, fitted at
one-degree assembly-phase increments, replaces that irregularity with uniform
working strokes. The selected phase is 76 degrees. Short C2 blends around the
two reversals avoid discontinuous velocity; the constant-speed portions occupy
94.91% of a revolution. The geometry correction is explicit, especially near
the drawn groove's upper and lower ends.

Centering the shaft in the barrel shifts its drawn axis by 0.66235 pixel.
Centering the rectangular rod on the crosspin shifts its drawn axis by
1.37489 pixels. The rounded pin replaces the source's pointed working end.
The rod translates rigidly with the follower head through the stationary
rectangular guides. The crosspin is interpreted as a rigid fastening, rather
than a free hinge. This attachment, the working pin shape, depths and ideal
shaft bearings are reconstruction assumptions. The engraving omits the shaft
bearing fixtures, so the model does not add a pedestal assembly.

Eleven closed solids preserve the rectangular guide bores and the ordinary
crosspin holes. The shaft has complete ends. Guide running clearance is
0.3 source pixel; the pin-to-hole radial clearance is 0.15 pixel.
Fog and ground are disabled.

## Groove and dynamics

The groove is generated by sweeping the full angular footprint of the rounded
pin, with walls ruled along radial rays. The floor is relieved by 1.01 source
pixels beneath the rounded end. Each barrel land is divided into 768 convex
six-vertex prisms, exactly filling the rendered solid; there is no convex hull
bridging the groove. Together with the native capsule pin this gives 1,537
contact geometries. The pin radius is 0.01 source pixel smaller than the cutter.

The native model has an input hinge about the barrel axis and an independent
output slide along it. Only the input hinge is actuated. The groove walls drive
the output through frictional contact; no output motor, spring or equality
supplies its motion. The ideal slide holds the rounded pin at its working
depth, so the relieved floor never contacts it and has no separate collider.
Independent finite-surface checks cover the remaining hardware clearances.

Defaults use a 0.5 ms timestep, implicit integration, gravity, a friction
coefficient of 0.03 and a 4 ms soft-contact response. The input position drive
requests constant rotation with velocity feed-forward. Uniform density is
normalized to unit barrel assembly mass, with inertia computed from the visible
solids. Density, friction, drive torque and contact compliance are uncalibrated;
the model demonstrates the motion rather than predicting manufacturing loads.

## Validation

Four mechanism tests and eleven shared runtime, engine and camera tests pass.
Ten consecutive revolutions check every native timestep, with contact recorded
on both walls and no stalled input or incomplete output stroke.

| Measurement | Bound observed |
| --- | --- |
| Follower deviation from the machining law | 0.019514 source pixel |
| Speed variation over 100 ms intervals on uniform flanks | 1.40215% |
| Native pin/land penetration | 0.004653 source pixel |
| Sampled visible pin/land penetration | 0.001688 source pixel |
| Minimum rod extension beyond either guide | 5.50248 source pixels |
| Travel difference, 0.5 versus 0.25 ms timestep | 0.031875 source pixel |
| Travel difference, 0.25 versus 0.125 ms timestep | 0.029964 source pixel |
| Travel difference with twice as many angular cells | 0.028949 source pixel |

Thirty-three poses over the first revolution pass 5,935,008 independent surface
samples. The only sampled intersections are the intended pin/land contacts.
Every visible vertex remains inside the camera bounds. All eleven solids have
consistent outward normals, closed edges and positive volume. The 9,216 compiled
collision vertices agree with the rendered land surfaces within 0.00003 source
pixel, and the prism volumes agree with the visible solids.

These are sampled geometry checks, not a continuous clearance proof. Velocity
variation is measured over 100 ms intervals, not at individual contact impulses;
the refinement results concern travel and do not establish force convergence.
Removing pin contact with gravity and initial output velocity disabled leaves
the follower stationary while the barrel rotates. Separate positive and negative
loads retain the stroke. Restart, seeking and different render-frame partitions
reproduce identical state, and disposal releases both native allocations.

Sixteen final views are inspected, covering source registration, both reversals,
intermediate phases, rear and oblique views, groove, follower, guide and crosspin
details, and desktop/mobile catalog controls. The first thirteen are byte-identical
to the inspected candidate. Shadow-caster isolation confirms that the dark
patches on the barrel and shaft are cast shadows from neighboring hardware.
Live headless playback averages 36.32 fps over 8.233 seconds at physical speed,
with 4.204 ms mean physics/update time and 5.300 ms at the 95th percentile.
There are no page errors or unexpected warnings; known Three.js notices remain.

The production build and all 22 MuJoCo browser tests pass, covering lazy loading
beneath a static subdirectory, playback, restart, mobile controls, section and
input controls for other movements, navigation races, asset retry and disposal.
The build retains its existing large-chunk and guarded Node-import warnings.

Local evidence uses `/dev/shm/106-source-final.json`, `106-tests-b.txt`,
`106-final-views.json`, `106-build-a.txt`, `106-e2e.txt` and
`106-final-inspection.json`. Bulk evidence remains outside Git.

## Reproduction

```sh
PROBE_PREFIX=/dev/shm/106-measured node scripts/measure-barrel-cam-source.mjs
TMPDIR=/dev/shm node --test tests/mujoco-barrel-cam.test.mjs tests/mujoco-runtime.test.mjs tests/engine.test.mjs tests/camera-resize.test.mjs
TMPDIR=/dev/shm npm run build
TMPDIR=/dev/shm npx playwright test tests/e2e/mujoco.spec.mjs --output=/dev/shm/106-browser-results-new
TMPDIR=/dev/shm PROBE_PREFIX=/dev/shm/106-new-views node scripts/capture-mujoco-barrel-cam.mjs
```

The capture uses an existing Vite server on port 5174. Use fresh exclusive
prefixes and one owned browser at a time; keep source and build files unchanged
during capture. The baseline script explicitly uses the historical registry
factory, while the final capture uses the production asynchronous loader.
